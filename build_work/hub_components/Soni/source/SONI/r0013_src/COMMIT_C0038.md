# C0038 — Hydrophone Unified Cavitation Scale

- CPC 8CH popup now uses the same fixed X range (0.0–1.0 MHz) on all panels.
- All channels use the same fixed Y range (-60 to 0 dB).
- Raw amplitudes remain unchanged internally.
- Display normalization is calculated once per channel across the entire selected sonication.
- Stable relative-dB display prevents proprietary/raw scale outliers from hiding subharmonic, ultraharmonic, and broadband cavitation components.
- Overlay and Single CH modes use the identical fixed scale.

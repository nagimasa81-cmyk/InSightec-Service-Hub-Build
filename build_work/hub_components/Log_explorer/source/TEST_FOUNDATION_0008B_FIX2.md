# Quick verification

1. Build with `Build_DEBUG_Console_EXE.bat`.
2. Start the application.
3. Select the same source folder and click START.
4. Confirm Smart File Discovery completes without an exception.
5. Confirm the Viewer opens.
6. Confirm WS and another pane can load.
7. Confirm column borders can be dragged.
8. Confirm Reset Layout and Fit Columns are visible.

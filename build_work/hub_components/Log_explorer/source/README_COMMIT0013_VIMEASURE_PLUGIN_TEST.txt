Commit0013 adds a tested File Type plugin workflow.

1. Build the main EXE from this Source ZIP.
2. Open PluginBuilder.py or build FileTypePluginBuilder.exe.
3. Use the VIMeasure preset and add two or more sample logs.
4. Run Tests. The ZIP can only be generated when all tests pass.
5. In Log Merge Tool, open Update File Type and install:
   sample_plugins/VIMeasure_FileType_Update_v1_0_0.plugin.zip
6. Reload and verify Smart Discovery, Viewer columns and Sonication Investigation.

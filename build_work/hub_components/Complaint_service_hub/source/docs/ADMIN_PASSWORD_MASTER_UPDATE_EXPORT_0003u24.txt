Complaint Service Hub 0003u24

- Enabling Admin Mode from an ordinary user session now always requires the Admin password.
- Incorrect passwords are rejected; three attempts are allowed per activation request.
- Disabling Admin Mode does not require a password.
- Master Manager now provides Save update.zip.
- The exported ZIP contains administrator-maintained masters, templates, profiles, an update manifest, creator, source build, file list and timestamp.
- Local config/settings.json is intentionally excluded so importing the package does not overwrite each PC user session, language, or paths.
- The generated package is accepted by the existing Update ZIP tool as a master update.

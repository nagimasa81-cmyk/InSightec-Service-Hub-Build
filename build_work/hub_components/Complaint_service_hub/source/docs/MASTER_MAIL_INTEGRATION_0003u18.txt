Complaint Service Hub Commit0003u18

Integrated sources
- masters/source/mailing.xlsx
- masters/source/SiteInfo.xlsx

Behavior
1. Complaint email recipients are generated by country.
   Every person marked with x in the corresponding Complaint country column is added to the To field.
2. Startup selection:
   - InSightec lists active InSightec users.
   - Distributor lists only users whose normalized role is Distributor FE.
3. SiteInfo drives hospital, serial, country, system, type, MR details, InSightec owner, distributor and distributor FE metadata.
4. Complaint output uses the same Outlook recovery pattern as Feedback:
   - active Outlook COM connection
   - up to three retries
   - Open Outlook action
   - template fallback
5. Outlook and template bodies remain English.

Notes
- Countries without a Complaint mailing column have no automatically configured recipients.
- Original spreadsheets are retained under masters/source for audit/reference.
